# VesperCodex

Monorepo for VesperCodex projects.

## Projects

### VesperMine ⛏️
Passive Bitcoin earning app with cloud mining dashboard & rewards system.
- **Platform**: Flutter (Android, iOS, Web)
- **Backend**: Firebase (Auth, Firestore, Cloud Functions)
- **State**: Riverpod
- **Location**: [`vespermine/`](./vespermine/)

## Getting Started

```bash
cd vespermine
flutter pub get
flutter run
```
